# مراجعة إنذارات الخصوصية لحزمة الإصلاح

هذه مراجعة تقنية لمواضع الإنذار، وليست ضمانًا لاكتشاف كل معلومة حساسة. تُربط قرارات الحسم ببصمة بايتات كل ملف وبصمة قائمة إنذاراته وإصدار الحارس في سجل مراجعة الحزمة. أي تغير يبطل الحسم القديم.

- ملفات المقاطع الثلاثة: حُسمت مواضع بيانات اتصال الناشر وتسميات النماذج الفارغة بمراجعة الصفحات الأصلية كما وثق `source_visual_review.md`؛ بقي النص كما كان.
- اختبارات Gate والخصوصية وسلامة المشروع: قُرئت مواضع الإنذار في الكود. هي قيم صناعية وتسميات حقول وأمثلة سلبية معزولة لإثبات المنع، وليست أسماء طلاب أو وقائع مدرسية أو جهات اتصال فعلية. لا يُستخدم مرور ملف الاختبار تصريحًا بحفظ بيانات حقيقية مشابهة.
- سجلات المحادثة: معرّفات السياق وأسماء ملفات الجلسات معرّفات محادثات اختبار فعلية مولدة في البيئة، وليست معرّفات طلاب أو أرقام اتصال. نصوص المواقف صناعية؛ لا ربط بطلاب فعليين أو توسيع للأحرف. يراجع الحارس ملفات الالتقاط والتحكيم نفسها قبل إدراجها.

لا يُنسخ النص المشتبه به إلى سجلات الحسم العامة. لم يُحذف أصل أو يُنقح بصمت. مراجعة الحزمة تستخدم قائمة صريحة للملفات وتفحص أعضاء ZIP وبصماتهم وCRC؛ استبعادات Git لا تحدد النطاق. لقطة الرجوع الكاملة محلية ومستقلة، وخارج حزمة المشاركة.
